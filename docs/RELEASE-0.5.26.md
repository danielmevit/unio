# Unio 0.5.26

This update focuses on dependable local operation before further dashboard, desktop or phone features. It combines host-aware storage checks, truthful interrupted-run observations, safe build-cache inventory, cheaper refusal of a protected full checkpoint store, AI CLI update awareness and Vibe compatibility.

## Operating boundaries

- Storage observations are point-in-time facts, not reservations. A Windows/WSL mapping that cannot be verified stays Unknown.
- Interrupted-run observations preserve original receipts and known failed exits. Missing proof stays Unknown.
- Cache inventory does not delete anything. Benchmark evidence and protected/latest/claimed checkpoints are not automatically pruned.
- A fast full-store refusal does not free checkpoint space or turn a failed save into a backup.
- `unio update clis --check` checks version facts. Installation requests remain refused/manual until native maintenance coordination prevents updating underneath admitted work. External/native updates and unmanaged sessions are not globally controlled.
- Vibe support is limited to exact tested versions2.26.1 and3.1.1. Existing numeric arguments remain compatible;3.1.1 accepts explicit `none` cap choices where supported. Omitted flags are not proof of unlimited native or subscription capacity. Low/medium thinking controls are not claimed on3.1.1; effective serving identity/effort remain Unknown.
- Execution remains `trusted_host`: worktrees and private fixture directories are not OS sandboxes.

## Verification and provenance

The release includes current-code checks, independent review and lead assessment. Detailed release evidence and asset hashes belong in the published provenance. Original Source failures, interrupted gate receipts and recovered work are retained rather than relabelled as successful process exits. Known operational failures are separate from code-quality findings.

The older, separately preserved local/cloud0.5.26 development branches are not merged by name or version alone. Only the reviewed work actually present in this release is included; unfinished follow-ups remain backlog.
