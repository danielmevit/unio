Add explicit required-delivery artifact contract (P1, Unio 0.5.23 candidate).

- New opt-in `## Required artifacts` section declares bounded text artifact delivery
- Engine-owned fresh per-run private delivery directory via UNIO_DELIVERY_DIR
- Strict metadata validation: count/size/type bounds, no duplicates, safe paths
- Artifact binding to exact task/worker/run/dispatch command and revision
- Source exit zero with missing artifacts yields incomplete delivery (not ready)
- Preserve actual Source exit, timeout/cancellation and provider-limit evidence
- Separate required-artifact validation from human acceptance authority
- No fabrication of missing data; incomplete delivery clearly visible
- Legacy tasks without declaration retain exact Unknown/undeclared behavior
- Report-only tasks: required artifacts are additional to report channel
- Implementation tasks: artifacts validated alongside existing commit gates
- No provider calls from observation/validation; no arbitrary shell evaluation
- Security: no path traversal, no symlinks, UTF-8 text only, bounded sizes
- New docs/development/REQUIRED-DELIVERY.md operating guide
- New tests/unio-required-delivery.py test suite
- Embedded guides: ADMISSION-DEADLINES, REVIEW-STATUS, REQUIRED-DELIVERY
