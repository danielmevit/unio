Stop the save capacity preflight from consuming the 64 MiB capture read allowance: its manifest reads now use a separate bounded metadata allowance (48 MiB, 256 archive entries) that falls through when exhausted, so saves the previous engine published (for example a 20 MiB manual save or a changed periodic save into a store of large manifests) are no longer falsely refused. The periodic archive scan now propagates only deadline and lock/unknown outcomes; unrelated unsafe or invalid archive entries no longer block an unchanged periodic no-op or replace the recorded refusal reason. This supersedes the "read charging" wording in SAVE-CAP-CORRECTION-20261110.
