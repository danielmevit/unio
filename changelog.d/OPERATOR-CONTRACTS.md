Canonical adapter route arguments are checked offline with the adapters’ actual parsers and bounds before run admission, retry, background start or provider metadata. Review and review-set use the same check. Thin per-run configs and copied engine binaries retain a frozen canonical-source bundle; no global helper is overwritten. Relocated adapter sources are recognized only when their bytes match that bundle. Custom, wrapped or unknown contracts remain callable and explicitly unvalidated. Diagnostics name options, bounds and remedies without echoing argument values. Vibe keeps thinking low/medium/high (default high), including 12M tokens within its 16M bound.
